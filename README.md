💎 MM Diamonds Inventory Management System

A full-stack Diamond Inventory Management ERP System built for managing diamond stock, customers, suppliers, sales, and reports in an efficient and organized way.

📌 Project Overview

MM Diamonds is a web-based ERP system designed to manage diamond business operations like:

Inventory tracking
Customer management
Supplier management
Sales & memo system
Reports and analytics dashboard
User authentication system
🚀 Features
🔐 JWT Authentication (Login/Register)
💎 Diamond Inventory Management
👤 Customer & Supplier Management
🧾 Sales & Memo Generation
📊 Dashboard with analytics
📁 Excel/CSV data import support
🌙 Dark luxury UI theme (Gold accents)
📦 Stock tracking system

⚙️ Installation & Setup
1. Clone the repository
git clone https://github.com/sbhavy1212-star/mmdiamond2.git
2. Go to project folder
cd mmdiamond2
3. Install backend dependencies
cd backend
npm install
4. Setup environment variables

Create .env file:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
5. Run backend server
npm start
